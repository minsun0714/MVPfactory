## 목적

역할별 에이전트가 실제 모델을 호출하고, 생성한 코드를 격리된 환경에서 설치·빌드·실행하도록 연결한다. 지금의 모의 산출물을 실제 코드 생성 결과로 바꾼다.

## 완료 조건

- [ ] 실제 프로젝트 파일이 생성되고, 계획이나 예시 텍스트만으로 구현 완료를 표시하지 않는다. (AC-006-1)
- [ ] 생성 코드를 프로젝트별 격리 환경에서 설치·빌드·실행하고 실제 결과를 기록한다. (AC-006-2)
- [ ] 빌드·기능 오류를 정해진 한도 안에서 수정하고 결과를 기록한다. (AC-006-3)
- [ ] 모델·도구 연결이 없으면 미연결·실패·차단으로 표시하고 데모 결과로 대체하지 않는다. (AC-006-4)
- [ ] 샌드박스에 팩토리 DB 연결 정보와 관리 토큰이 들어가지 않는다.

## 검증 방법

기준 앱으로 실제 모델과 샌드박스를 사용해 수행한다. 샌드박스를 삭제한 뒤 저장된 소스 스냅샷에서 복원되는지도 확인한다. DEC-002(모델), DEC-004(실행 환경)가 정해져야 시작할 수 있다.
