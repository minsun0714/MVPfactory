## 목적

배포 후 받은 피드백으로 새 Run을 만들어, 같은 GitHub 저장소·DB·Vercel 프로젝트에 변경을 반영한다. 기존 데이터와 유지 대상 기능을 보존해야 한다.

## 완료 조건

- [ ] 수정 Run이 이전 사양·결정·코드·DB 구조를 이어받고 변경 범위를 기록한다. (AC-012-1)
- [ ] 새 저장소·DB·배포 프로젝트를 만들지 않고 기존 것을 재사용한다. (AC-012-2)
- [ ] "공부 시간 추가" 후 기존 기록과 기존 기능이 유지된다. (AC-012-3)
- [ ] 데이터 손실 가능성이 있는 변경은 영향과 선택지를 제시하고 자동으로 진행하지 않는다. (AC-012-4)
- [ ] 수정 실패 시 마지막 정상 결과와 새 실행의 실패 내용을 구분해 보여 준다. (AC-012-5)

## 검증 방법

PRD §13.1의 기준 앱과 후속 요청("공부 시간을 추가해줘")으로 실제 DB·저장소·배포에서 수행한다(TC-003).
