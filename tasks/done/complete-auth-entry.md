## 목적

로그인만 있고 계정을 만들 방법이 없는 생성 앱을 줄인다. PM·기획·디자인과 Codex 생성·수정에 일관된 계정 진입 규칙을 전달한다. 이번 범위는 생성 지침 개선이며 실제 인증 공급자 구성이나 브라우저 인증 검증 구현은 포함하지 않는다.

## 완료 조건

- [x] REQ-004·005: 신규 사용자 계정 획득과 첫 사용 흐름, 오류·복구 상태를 지시한다.
- [x] REQ-006: Codex 작성·수정에도 같은 규칙이 전달된다. 초대 전용 등 명시된 제한을 보존한다.
- [x] 지침 검증과 실제 생성 앱 인증 검증의 차이를 문서에 기록한다.

## 검증 방법

관련 에이전트·Codex 테스트, 타입 검사, 관련 lint·서식 검사. 실제 모델 생성과 배포 앱 회원가입은 별도 미검증으로 기록한다.

검증 결과: 관련 테스트 22개 통과, 타입 검사·관련 ESLint·서식 검사 통과. 실제 모델 생성·배포 앱 회원가입은 미검증. 변경은 지침과 문서에 한정하며 빌드는 재실행하지 않았다.

후속 결정(2026-11-22): `exclude-generated-auth`에서 생성 앱 인증을 범위 밖으로 변경하여 이 작업의 회원가입 기본 포함 지침을 대체했다.
