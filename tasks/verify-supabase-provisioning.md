## 목적

준비된 Next.js 기준 앱으로 실제 Supabase 프로젝트를 만들고, 스키마를 적용하고, 데이터를 저장하는 전체 경로를 검증한다. 지금은 외부 연동이 자리만 잡힌 상태이므로 모의 성공이 아닌 실제 결과가 필요하다.

## 완료 조건

- [ ] 연결된 조직에 DB 프로젝트를 만들고 준비 상태를 확인한다. (AC-007-2)
- [ ] 선언형 스키마 계획으로 테이블·제약·접근 정책을 적용하고 실제 스키마를 조회해 확인한다. (AC-007-2)
- [ ] 생성·조회·수정·삭제와 재접속 후 조회가 실제 DB에서 동작한다. (AC-007-4)
- [ ] 연결 실패 시 브라우저 저장이나 샘플 데이터로 바꾸지 않고 실패로 표시한다. (AC-007-6)

## 검증 방법

기준 앱(공부 기록 앱)으로 실제 계정에서 수행한다. 자격 증명이 없어 수행하지 못한 항목은 "미검증"으로 기록한다.
