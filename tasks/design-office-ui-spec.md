## 목적

아이소메트릭 사무실과 업무 패널의 실제 화면 기준을 정한다. 대표 시안을 검토한 뒤 사용자 승인 결과를 명세에 기록한다.

## 완료 조건

- [x] 사무실 기본 화면과 업무 패널 열린 화면의 시각 초안을 제공한다. (AC-010-2)
- [x] 캐릭터 4명·꾸미기 진입·회의 공간·CEO 응답 위치를 표시한다. (AC-015-4, AC-016-2)
- [x] 제안 상태·예시 데이터·미구현 기능을 구분한다.
- [ ] 사용자가 시안을 검토하고 승인하거나 수정 의견을 반영한다.

## 검증 방법

브라우저에서 두 시안 전환과 PNG 결과를 확인한다. 문서의 이미지·상대 링크와 포맷을 검사한다. 실제 API·꾸미기·회의 기능의 완료 증거로 사용하지 않는다.
