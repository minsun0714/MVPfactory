## 목적

실제 모델과 실제 연동으로 얻은 실패 사례를 모아, PM·기획자·디자이너·개발자의 지침과 문맥 구성을 개선한다. 같은 기준 과제와 같은 측정 기준으로 전후를 비교한다.

## 완료 조건

- [ ] 개선 전 기준값(성공률, 수정 횟수, 시간, 비용)을 같은 과제에서 측정해 기록한다.
- [ ] 개선 후 같은 조건에서 다시 측정해 비교한다.
- [ ] 기획 산출물에서 사용자 확정 사항과 에이전트 가정이 구분된다. (AC-004-1)
- [ ] 화면 설계에 빈 상태·로딩·입력 오류·저장 실패가 포함된다. (AC-005-2)

## 검증 방법

고정한 기준 과제로 개선 전후를 비교한다. 실패를 제외해 수치를 높이지 않는다(PRD §14).
